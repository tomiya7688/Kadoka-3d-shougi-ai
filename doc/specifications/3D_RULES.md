# 三次元将棋ルール整理 — 将棋ったー版

> Status: Draft。2026-10-16に公開ページを確認。**以下の「資料で確認できる事項」と「未確認」を必ず区別する。**

## 正本と座標系

- 基準: [将棋ったー「三次元将棋」](https://shogitter.com/rule/三次元将棋) / [駒の動き一覧](https://shogitter.com/rule/三次元将棋/koma)。
- 9×9×9＝729マス。筋・段・層をそれぞれ `x,y,z` （各1..9）とする。
- **前方**: 先手は y が減少する方向、後手は y が増加する方向。z は両者共通の上下方向。
- **二歩**: 同じ `z` 層かつ同じ `x` 筋の二歩を禁止（他の層の同じ筋は別）。
- **勝利条件**: 相手の王将を詰ませる。
- 初期陣は7段目に歩、8段目に角・飛、9段目に玉を中心とする金・銀・桂・香の同心四角形。**具体的な3座標と枚数は、対局開始画面からfixture化して確定する**。

## 駒の移動（移動先形状。実際の着手には盤外・味方・遮蔽などの検証が必要）

| 駒 | 公開説明から確認できる動き |
| --- | --- |
| 王将 | 現在地から各軸差 `-1,0,1` の計26近傍（差が全て0を除く）へ1マス |
| 歩兵 | zを変えず、前方（y）に1マス |
| 香車 | 同じz層で前方に走る（駒にぶつかるまで） |
| 桂馬 | 前方へyを2進め、xとzをそれぞれ±1ずらした4マスへ跳ぶ |
| 銀将 | 前方yへ1のx方向3×z方向3＝9マスと、後方yへ1の上下z層の斜め4マス（合計13） |
| 金将 | 26近傍から、同z層の斜め後方2マスと、上下z層の後方各3マス（計8）を除く18マス |
| と金・成香・成桂・成銀 | 金将と同じ18マス |
| 飛車 | **始点と終点が x/y/z のいずれか1座標を共有**する地点へ。共有座標を固定した面への広がり。遮蔽に特殊ルールあり |
| 角行 | `max(|dx|,|dy|,|dz|)` が **少なくとも2成分** で同値の地点へ。遮蔽に特殊ルールあり |
| 竜王 | 飛車の動きと王将の26近傍の和集合 |
| 竜馬 | 角行の動きと王将の26近傍の和集合 |

### 走り駒の遮蔽（重要）

**飛車**: 始点と終点を対角とする、境界面を含む軸平行直方体の中の駒を飛び越せない。移動先の相手駒は捕獲可能。2Dの1本の直線rayで判定する実装では不十分。

**角行**: 『45度長方形方式』。利きを12枚の二等辺三角形の面に分割し、同一面上の駒の1段先から幅3・5・7…と広がる範囲が遮られる。面外の駒に遮られず、遮る敵駒のマスには捕獲目的で移動できる。説明だけを一般の3D直線遮蔽へ置き換えてはならない。

遮蔽の厳密アルゴリズム・重複面境界・captureの場合の判定順序は、参照対局盤を使ったサンプル入力／期待出力の収集後に独立Issueで確定する。

## 空盤の移動先候補数（(5,5,5) を起点、外周内・遮蔽なし）

- 王将: 26。
- 飛車: 216（x/y/zのいずれか1座標が起点と同じで、起点自身を除く）。
- 角行: 224（絶対座標差の最大が2軸以上で等しく、起点を除く）。
- これらは**候補の幾何学的な数**であり、王手や他駒による合法手数ではない。

## 要検証・未決事項（推測で実装しない）

- 初期配置の全729マス（先後の鏡像、層ごとの具体的枚数）。
- 成りエリアと成りの可否・強制成り、歩・香・桂の打ち禁止段の正確な適用。
- 持ち駒の打ち歩詰め、千日手・連続王手、持将棋、入玉宣言、引き分け・不正局面の扱い。
- 将棋ったーの内部仕様や実際の対局と照合した玉の移動先安全性、複雑な飛車角の遮蔽・成駒の利き。
- 対局データ取得の可否、利用規約、ライセンス、および自動テストに使える形式。

不明点を自作ルールで補う場合は、**将棋ったー互換モードとは明示的に分離**し、仕様に根拠と変更履歴を記す。

## 推奨テストケース

1. 盤中央の空盤で王26／飛216／角224候補。
2. 王将が外周・頂点にいるときの境界クリップ（頂点では7近傍）。
3. 先手/後手の歩・香・桂・銀・金の前方方向。
4. 飛車: 固定z面・固定x面・固定y面それぞれの候補と遮蔽。
5. 角行: (2,2,0)、(2,2,1)、(2,2,2)を許容し、(2,1,0)を不許容とする幾何学条件（盤内の位置から試す）。
6. 駒が飛車の直方体の内部／境界にあるときのブロック、角の同一三角面／面外ブロック。
7. 層違いの同筋歩が二歩にならないこと。同じ層・筋の歩は二歩。
8. 移動先味方禁止・相手捕獲・王手放置禁止・王将が利きへ移動禁止。
