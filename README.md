# Kadoka 3D Shougi AI

9×9×9（729マス）の三次元将棋に対応する、Kadoka Shougi AI 系列の実験的AI／将棋ゲーム基盤プロジェクト。

> **現状（2026-10-16）**: リポジトリ初期整備・仕様策定フェーズ。ここに記載する設計やAIファミリーは、実装済みを意味しません。

## 目標

- [将棋ったー版「三次元将棋」](https://shogitter.com/rule/三次元将棋) の9×9×9ルールを検証可能な形で実装する。
- [本家 Kadoka Shougi AI](https://github.com/tomiya7688/Kadoka-shougi-ai) の、AIがなくても動く独立したゲームCoreと、差し替え可能なAI・Runtime・学習基盤という設計思想を踏襲する。
- まず本家で**既に実装されている基盤**への追随を目指し、続いて本家の**計画中の機能**へ拡張する。
- 通常将棋の2次元の駒の利きや81マス表現を流用したままにしない。3D固有の合法手・遮蔽・性能問題を先に検証する。

## 最初に取り組むこと

1. 将棋ったー版の初期局面・各駒の移動・飛車角の遮蔽をテスト可能な仕様として確定する。
2. C++20のCore骨格、729マスの局面、3D指し手、局面往復変換を実装する。
3. 擬似合法手 → 王手判定 → 合法手 → 1局の完走まで進める。
4. Runtime／Player API／対局記録／CIなど本家で実装されている基盤を3D向けに移植する。
5. AI検索・学習・UI・リーグなど本家の計画中機能を、動作するCoreの上に積み上げる。

**Issue**: [タスク一覧](https://github.com/tomiya7688/Kadoka-3d-shougi-ai/issues)。IssueのP0/P1/P2は相対的な開発優先度です。

## 注意事項

- 「三次元将棋」には別解釈があり得るため、本プロジェクトのルール基準を将棋ったー版に固定します。仕様が公開ページだけでは確定しない部分は「未決」として記録し、実装で推測を既成事実化しません。
- 棋譜、SFEN、USI等の2次元向けフォーマットに、未定義の3D拡張を標準互換だと称して持ち込みません。
- 本家のコード・技術ドキュメントを再利用する場合はライセンス表示を引き継ぎます。公式キャラクター名・外観の取り扱いは、本家の別建てライセンスを確認します。
